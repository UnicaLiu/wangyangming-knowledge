核心问题：账号为何无法被信任？05:55
用户做短视频的根本目的
回顾上节课内容，明确大家做短视频的目标是“我要赚钱”。
当前普遍做法及其困境
有产品的账号只卖产品；
卖服务的账号只讲行业话题；
卖知识的账号只输出干货；
无方向者通过互粉凑粉丝后挂商品橱窗。
失败原因分析
上述做法导致账号在用户眼中不是“人”，而是“卖货的”、“干装修的”或“想开超市的”。
核心问题是：我们让人认识的是商品、服务或知识，而不是我们这个人本身。
信任缺失的后果
没有信任基础，就无法影响用户决策，导致卖不出去东西。
信任获取效率层级：人大于品牌大于产品 09:03
思维实验：推荐一款“宇宙空调”
描述一款功能强大的空调（识别位置吹风、除甲醛、恒温恒湿、造氧等），售价3万元。
提问观众是否相信该产品。
逐步增加可信度因素
加入“品牌”因素：由航空设备制造商量产家用化，可信度略有提升。
加入“IP/人物”因素：由伊隆·马斯克宣布研发并用于火星计划，可信度显著增强。
结论提炼
获取信任的效率顺序为：人 > 品牌 > 商品。
实例佐证：
董明珠之于格力
雷军之于小米
董宇辉之于东方甄选
核心观点
成为影响者，即拥有“你让别人买什么，别人就买什么”的能力，其前提是获得用户的信任。
需求的网状结构与KOC理论基础 16:28
横向需求度与纵向需求群模型
用户的需求是网状的，而非单一。
每个用户都处于多个需求交叉点上，形成复杂的“需求群”。
案例分析：女性成长博主的成功逻辑
同一类人群可能同时对围巾、美妆、书籍、情感咨询感兴趣。
当博主的多个标签与用户高度重合时，用户会产生强烈信任感。
根本原因
多维度的标签重合带来高信任度，使用户愿意为其推荐的一切买单。
KOC的六大属性 36:36
够得着信得过
KOC必须是用户觉得亲近且可信赖的人。
不可替代性
在特定组合场景下，KOC的角色无法被专家完全取代（如妇产科主任 vs. 有经验的母亲）。
标签多元化
个体拥有多重身份和兴趣标签。
多需求人群忠诚度最高
与KOC多个标签重合的用户群体忠诚度最高，构成铁粉基本盘。
也可满足单一需求
KOC也能服务于仅对其某一标签感兴趣的用户，但这类用户可替代性强。
总结归纳
我们作为一个人，标签多元化 → 具有一定不可替代性 → 多需求人群标签重合度高 → 通过手机交互感知人格 → 觉得够得着、信得过 → 主要商业价值来自多需求人群 → 同时兼容单一需求以扩大体量。
KOC的两种存在形式 44:55
对象KOC
定义：内容聚焦于帮助或取悦某个特定对象（如老公、孩子、弟弟）。
吸引机制：引发目标对象的情绪共鸣，从而吸引与其相似的人群。
案例1：东哥每条视频对媳妇好 → 吸引希望丈夫也如此对待自己的女性。
案例2：“懒妈不懒”账号 → 每天给孩子做好吃的 → 吸引的是男性小学生而非宝妈。
风险：若对象无消费能力，则难以变现。
自我KOC
定义：内容围绕自身生活、情绪、价值观展开，为自己而表达。
吸引机制：真实状态引发同类人群共鸣。
案例：川川同学（一亩田）展示自律且享受的生活方式 → 吸引向往同样生活的女性 → 私域训练营月入数十万。
关键原则：真实。只有真实的内容才能建立深度连接。
内容创作的本质：推己及人 01:00:25
核心方法论
内容创作就是做人，表达真实的所思所想。
操作建议
深挖自己：观察自己的情绪反应、消费行为、兴趣偏好。
反思触发点：为什么某条视频让我感动？我为什么想买这个产品？
表达真实情绪：职场受挫、恋爱矛盾、生活感悟皆可成为内容。
定位误区破除
不需要刻意寻找“垂直领域”。
“你就是你的定位”，账号应反映完整的你。
账号战略：垂直于人群而非需求 01:05:10
错误策略：垂直于需求
如只讲车、只讲装修，会导致开口太小，形同“吸管”而非“漏斗”。
正确策略：垂直于人群
账号应围绕一个核心人群展开，覆盖其多种需求。
多条视频共同构建一个立体的人设，让用户全面了解你。
用户筛选机制
喜欢你的人自然会被吸引，不喜欢的会自动离开。
粉丝数是虚的，真正的粉丝是那些长期互动、愿意付费的人。
商家的终极打法：商业个人化 01:20:45
平台生态三角关系
平台需要用户 → 利用博主创造优质内容吸引用户。
博主需要流量 → 利用内容刺激用户互动以获取推荐。
商家不在这个基础平衡态中。
商家的两种出路
付费买流量（广告投放）。
寄生于博主身份之下，即走“商业个人化”路线。
第一身份必须是KOC
案例1：龙飞律师先做情感博主，再转化法律咨询客户。
案例2：周鸿祎作为科技评论博主，而非360公司代言人。
案例3：讲师本人以传递价值为主，卖课为辅。
反垂直内容策略
前半段内容广开流量入口（非垂直），建立信任。
后半段引导至商业闭环（垂直），完成转化。
实操案例推演：不同行业的KOC应用 01:30:52
修车大哥的账号策略
错误做法：发“高速异响的五个原因” → 用户不需要时刷到，需要时已错过。
正确做法：以修车工身份聊婚姻、人性、社会事件 → 吸引有车男性建立信任 → 未来修车首选他。
变现延伸：可带汽车用品，收入可能超过线下维修。
装修公司老板娘的账号策略
不直接讲装修，而是分享穿衣品味、夫妻相处、育儿观念等内容。
这些内容对应潜在客户的纵向需求群（如结婚→买房→装修）。
通过全方位展示审美与生活态度，建立深度信任，成为装修首选。
