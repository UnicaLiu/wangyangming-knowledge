# 王扬名 Day1：必拿流量的高商业价值内容打法

> 来源：[1必拿流量的高商业价值内容打法](../04-课程文稿/Day1-必拿流量的高商业价值内容打法.md)

## 核心观点

- **流量 ≠ 商业价值**：700 万粉丝黄老师 350 万人观看直播 → 仅 5-7.5 万销售额；4000 人观看的茶叶账号 → 同等销售额
- **平台是大众服务系统**：赛马机制下，垂直内容因受众窄无法通过自然推荐
- **传统"垂直"四大缺陷**：数量少、竞争大、消化快、转化难

## 核心模型：横向需求度

以"汽车贴膜"为例，用户需求不是突然产生的，而是沿着一连串条件逐步演化：
`25-40岁有车 → 刚买车 → 希望与众不同/吸引异性 → 想贴膜`

**三类打法**：
- **往前打（拿流量）**：面向更大基数的潜在人群
- **往后打（做转化）**：推动进入购买决策
- **打中间（种草影响）**：建立信任，提前植入需求

## 核心公式

> **谁影响 → 谁转化**

不应争夺已被他人影响的用户，应在需求萌芽阶段成为"影响者"。
