# 王扬名抖音账号矩阵及商业IP孵化模式深度研究

## 账号矩阵

- **主号（37万粉丝）**：爆款案例拆解、起号方法论、流量算法解读——建立"实战派短视频运营"专业认知
- **第二账号**：个人生活背书、学员见证、实操直播——信任深耕与私域转化

## 孔夫子人设模型

六维度构建可信人设：

| 维度 | 功能 |
|------|------|
| 能力 (Ability) | 展示专业技能、资质、成就 → 建立初次信任 |
| 突发反馈 (Reaction) | 对外界变化的即时真实回应 → 增加真实感 |
| 起因 (Origin) | 交代创作/创业动机与价值观来源 → 建立情感共鸣 |
| 态度 (Attitude) | 对行业现象表达鲜明立场 → 筛选志同道合者 |
| 感悟 (Perception) | 基于经验的深度总结与哲学思考 → 提升获得感 |
| 发心 (Intention) | 强调长期目标与价值贡献 → 建立长效信任 |

## 双轮驱动商业模式

- **内容为王**（跨边网络效应）：主号专业拆解获取公域流量
- **社交至上**（同边网络效应）：人设模型建立导师级社交连接
- **变现**："扬名商业IP孵化训练营"，累计学员 15 万+
