# 王扬名 Day3：落地推演——拿流量、获信任、促转化的内容方向

> 来源：[3落地，手把手带你推演，能拿流量，获信任，促转化的内容方向](../04-课程文稿/Day3-落地推演-拿流量获信任促转化.md)

## 核心观点

- **内容边界 = 对什么人群提供什么价值**：边界太窄无流量（只讲专业干货），太宽无效（盲目拍段子）
- **社交平台本质不是内容平台，是社交平台**：影响力建立在真实连接上

## 实操三步法

### 第一步：定用户
- 单一用户群体 vs 多用户群体
- 起号阶段聚焦一个群体，用 KOC 逻辑选最了解的人群

### 第二步：搭条件（横向需求度）
- 推演人群画像 → 描写需求 → 圈定条件 → 按人群基数排序
- 例：买房需求 ← 有生育计划 ← 已结婚 ← 准备结婚 ← 儿子恋爱到婚龄

### 第三步：扩需求（纵向需求群）
- 在每个横向节点上挖掘具体痛点
- 例：准婆婆与准儿媳关系、彩礼博弈 → 每个方向可延伸 20+ 选题

## 撒网收网模型

| 阶段 | 目的 | 示例 |
|------|------|------|
| 撒网 | 获取流量 + 人设信任 | "当年哥遇到最渣的渣女，花了20万血本无归" |
| 收网 | 透传专业 + 商业预期 | "那些收费贵但自己花小钱就能解决的修车问题" |

## 商家 vs 个人路径

- **商家**：产品 → 定人群 → 搭横向需求度 → 扩纵向需求群 → 找社交话题 → 撒网收网
- **个人**：我是谁 → 标签即内容方向 → 触达用户 → 发现需求 → 匹配商品 → 实现转化
