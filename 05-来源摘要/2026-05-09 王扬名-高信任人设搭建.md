# 王扬名 Day2：推荐什么用户就买什么的高信任人设搭建

> 来源：[2推荐什么用户就买什么的高新人人设搭建](../04-课程文稿/Day2-推荐什么用户就买什么的高信任人设搭建.md)

## 核心观点

- **信任获取效率**：人 > 品牌 > 产品（有董明珠才有格力，有雷军才有小米，有董宇辉才有东方甄选）
- **你卖的不是产品，是生活方式和解决方案**
- **"推己及人"**：你就是你的定位，不需要刻意找垂直领域

## KOC 六大属性

| 属性 | 说明 |
|------|------|
| 够得着信得过 | 用户觉得亲近、可信赖 |
| 不可替代性 | 特定组合场景下无法被专家取代 |
| 标签多元化 | 个体拥有多重身份和兴趣标签 |
| 多需求人群忠诚度最高 | 标签重合度高的用户构成铁粉 |
| 也可满足单一需求 | 兼容只对某一标签感兴趣的用户 |
| 标签重合 → 信任 → 影响 | 多维标签重合带来高信任，用户愿为其推荐的一切买单 |

## 两种 KOC 模式

- **自我KOC**：表达真实自我 → 吸引同类人群
- **对象KOC**：内容聚焦于帮助/取悦特定对象（老公、孩子等）→ 吸引以该对象为代表的人群

## 商业个人化

商家第一身份必须是博主/KOC，而非"卖货的"。案例：龙飞律师先做情感博主再转化法律咨询；周鸿祎做科技评论博主而非 360 代言人。
