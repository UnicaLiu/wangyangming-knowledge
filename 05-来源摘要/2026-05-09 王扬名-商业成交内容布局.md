# 王扬名 Day4：影响用户购买行为的商业成交内容布局

> 来源：[4影响用户购买行为的商业成交内容布局](../04-课程文稿/Day4-影响用户购买行为的商业成交内容布局.md)

## 核心观点

- **成交是影响出来的**：每个人在线下都是成功的 KOC——曾无意识向亲友推荐产品，但线下无收益，线上可以
- **卖的不是产品本身，而是场景和解决方案**

## 核心公式：关系决定目的

```
关系 → 目的 → 情绪 → 互动 → 数据（流量）
```

- 案例：妈妈教挑菜视频爆火 vs 商家直接卖菜被划走——同一内容，不同身份产生截然不同的效果
- **对事儿用技巧，对人要用情**

## 完整转化路径

```
触达用户 → 建立关系/获取信任 → 影响需求 → 达成成交
```

## 内容三部曲布局

| 类型 | 目的 | 示例（卖耳机） |
|------|------|---------------|
| 流量内容 | 争议性、价值观展示 | "女孩喜欢的东西一定要用自己的努力来买" |
| 影响内容 | 顺应人性、铺垫消费心理 | "年轻人一定要把钱花在取悦自己身上" |
| 成交内容 | 场景+解决方案 | "人只有在学会享受孤独之后才能长大，好的耳机是独立的小世界" |

> 本质：卖的是"对抗孤独的建议"和"大哥的人生经验"，而非耳机本身。

## 关键原则

- 信任和商业目的出现的先后顺序决定效果——先信任，后商业
- 关系有边界：你的外貌、性格、身份决定别人能否信任你卖某样东西
