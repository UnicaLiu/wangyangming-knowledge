## 💡 核心金句

> "流量 ≠ 商业价值。700 万粉丝不如 4000 人信任。"

> "成交是影响出来的。每个人在线下都是成功的 KOC。"

> "你卖的不是产品本身，而是场景和解决方案。"

> "商家第一身份必须是博主，而非卖货的。"

> "信任和商业目的出现的先后顺序决定效果——先信任，后商业。"
