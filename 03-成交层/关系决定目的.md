# 关系决定目的

> 用户与创作者之间建立的"关系"决定了用户如何看待创作者的目的。同样内容，不同关系产生截然不同的效果。

## 核心公式

```
关系 → 目的 → 情绪 → 互动 → 数据（流量）
```

## 案例

- **妈妈教挑菜**（爆火）：一口一个"孩子"建立母子关系 → 用户感受到关怀而非推销
- **商家卖菜**（被划走）：同样内容由穿制服的商家来讲 → 被认定为"想卖菜"，触发戒备

## 关键原则

- **对事儿用技巧，对人要用情**：修车大哥两种结尾对比——"关注我教你修车" vs "老弟出门在外能省就省"
- **发心决定内容温度**：用户能感知你的真实动机
- **关系有边界**：年轻小姑娘不适合做投资顾问，成功商界大佬不适合做身心灵——外貌、性格、身份决定信任边界
